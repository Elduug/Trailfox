# Security and privacy policy

## Supported versions

Security and privacy fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please do not disclose a vulnerability or unredacted diagnostic report in a public issue. Use [GitHub private vulnerability reporting](https://github.com/Elduug/trailfox/security/advisories/new). If that feature is unavailable, contact [@Elduug](https://github.com/Elduug) through GitHub without including sensitive evidence in the first message.

Include the affected version, macOS version, reproduction steps, impact, and a minimal sanitized example. You should receive an acknowledgment within seven days.

## Data-handling note

Trailfox runs locally and does not transmit reports, but collected evidence can contain usernames, hostnames, paths, network addresses, SSIDs, installed applications, and organization details. Review the sanitized report before sharing it and avoid attaching raw reports to public issues.
